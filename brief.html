03

How the apps connect

Four separate apps, but cases and letters flow between them. Select an app to highlight its links.

04

Where a report goes, and to whom

HR always receives every Employee Voice report and every manager report. The Division Chief and Division Director receive it only when chosen. Try a category.

05

Case lifecycle in People Manager

A manager report or an Employee Voice report can become an ER case. HR decides. Select a stage to see what happens there and which letters it produces.

06

Timebound cases

Any case can be a formal grievance or not. Timebound types get due dates in working days (Friday and Saturday excluded). Choose a type and an opening date to see the due dates the apps would set.

Sample values. HR sets them in Settings to match the Disciplinary Procedure, Grievance Procedure and Sexual Harassment Policy; open cases pick up changes straight away.

07

Reference numbers

The system creates every number. It runs in sequence per prefix and year, is never reused and cannot be edited. Letter numbers are given only on issue, so drafts never use one.

Status and decisions

What is ready for review now, what P&C needs to decide before build, and what comes later.

Ready now

  • Four CRs, one per app, version 0.3
  • Four clickable prototypes with Staff, Manager and HR views

Decisions needed
